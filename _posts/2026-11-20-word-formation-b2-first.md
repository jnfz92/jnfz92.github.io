La **Parte 3 del Reading and Use of English del Cambridge B2 First** puede parecer difícil porque no hay opciones entre las que elegir: tienes que construir la palabra correcta a partir de otra que aparece en MAYÚSCULAS. La buena noticia es que existe un método bastante sistemático para resolverla.

En esta guía aprenderás a identificar qué tipo de palabra falta, qué prefijos y sufijos debes conocer y cómo evitar los errores que más puntos cuestan en el examen.

## 1. ¿En qué consiste Word Formation?

En la Parte 3 encontrarás un texto corto con **ocho huecos**. Al final de cada línea aparece una palabra base en mayúsculas. Debes transformarla para que encaje en el hueco tanto por gramática como por significado.

- **8 preguntas**, más un ejemplo inicial.
- **1 punto por cada respuesta correcta**.
- Debes escribir **una sola palabra** derivada de la palabra propuesta.
- La ortografía debe ser correcta.
- Cada palabra base corresponde únicamente al hueco de su línea.

Por ejemplo:

> The hotel offers an ______ selection of activities. (IMPRESS)

La palabra que falta describe al sustantivo *selection*, así que necesitamos un adjetivo: **IMPRESSIVE**.

## 2. El método en cuatro pasos

No empieces añadiendo sufijos al azar. Sigue este orden:

### Paso 1. Lee la frase completa

El contexto te dice qué significa la palabra y si necesitas una idea positiva o negativa. No traduzcas palabra por palabra: entiende la oración.

### Paso 2. Identifica la categoría gramatical

Mira las palabras que rodean el hueco:

| Pista en la frase | Lo que suele faltar | Ejemplo |
|---|---|---|
| a / an / the + hueco | Sustantivo o adjetivo + sustantivo | a **decision** |
| hueco + sustantivo | Adjetivo | a **beautiful** view |
| verbo + hueco | A menudo, adverbio | speak **clearly** |
| be / seem / become + hueco | Adjetivo | seems **useful** |
| preposición + hueco | Sustantivo o gerundio | with **confidence** |

Son pistas, no reglas absolutas: comprueba siempre la estructura completa.

### Paso 3. Decide qué transformación necesitas

Puede que tengas que añadir un sufijo, un prefijo, cambiar una letra o poner la palabra en plural.

### Paso 4. Comprueba significado y ortografía

Lee la frase con tu respuesta. Pregúntate: ¿tiene sentido?, ¿concuerda con el sustantivo?, ¿necesita plural?, ¿está bien escrita?

## 3. Los sufijos más útiles

Los sufijos se añaden al final de una palabra para crear otra categoría gramatical.

### Para formar sustantivos

| Sufijo | Ejemplo |
|---|---|
| -tion / -sion | inform → information |
| -ment | improve → improvement |
| -ness | happy → happiness |
| -ity | possible → possibility |
| -ance / -ence | perform → performance; differ → difference |
| -er / -or | teach → teacher; act → actor |

### Para formar adjetivos

| Sufijo | Ejemplo |
|---|---|
| -ful | care → careful |
| -less | hope → hopeless |
| -ous | danger → dangerous |
| -ive | impress → impressive |
| -able / -ible | rely → reliable; access → accessible |
| -al | nature → natural |
| -y | storm → stormy |

### Para formar adverbios

| Sufijo | Ejemplo |
|---|---|
| -ly | quick → quickly |
| -ily | easy → easily |
| -ically | basic → basically |

**Truco:** si el hueco describe cómo se realiza una acción, probablemente necesites un adverbio: *She answered politely.*

## 4. Prefijos negativos: cambia el significado

A veces la palabra necesita expresar lo contrario. Estos son algunos prefijos frecuentes:

| Prefijo | Ejemplo |
|---|---|
| un- | happy → unhappy |
| in- | correct → incorrect |
| im- | possible → impossible |
| il- | legal → illegal |
| ir- | regular → irregular |
| dis- | agree → disagree |
| mis- | understand → misunderstand |

No todos los adjetivos aceptan todos los prefijos. Aprende las formas habituales como parte de cada familia de palabras.

Ejemplo:

> It is ______ to finish the whole project in one hour. (POSSIBLE)

El contexto indica que no se puede hacer: **IMPOSSIBLE**.

## 5. Cambios internos y plurales

No todas las respuestas se forman añadiendo letras al final. Algunas palabras cambian por dentro:

| Palabra base | Transformación |
|---|---|
| long | length |
| strong | strength |
| wide | width |
| deep | depth |
| choose | choice |
| speak | speech |
| succeed | success |

También debes fijarte en el número:

- attract → attraction → **attractions**
- possibility → **possibilities**
- activity → **activities**

Si antes del hueco aparece *many*, *several*, *various* o *a number of*, comprueba si necesitas un sustantivo plural.

## 6. Familias de palabras que debes aprender

No memorices palabras aisladas. Aprende varias formas de una misma raíz:

| Verbo / raíz | Sustantivo | Adjetivo | Adverbio |
|---|---|---|---|
| succeed | success | successful | successfully |
| compete | competition / competitor | competitive | competitively |
| decide | decision | decisive | decisively |
| differ | difference | different | differently |
| care | care | careful / careless | carefully / carelessly |
| impress | impression | impressive | impressively |
| rely | reliability | reliable | reliably |
| attract | attraction | attractive | attractively |

No todas las familias tienen todas las categorías. Lo importante es conocer las formas que realmente existen y cómo se usan.

## 7. Errores frecuentes en el examen

1. **Elegir una palabra relacionada, pero de categoría incorrecta.** *Impression* es un sustantivo; *impressive* es un adjetivo.
2. **Olvidar el adverbio.** Después de un verbo, puede que necesites *highly*, no *high*.
3. **No detectar una negación.** *Possible* e *impossible* tienen significados opuestos.
4. **Olvidar el plural.** *Attraction* y *attractions* no son intercambiables en cualquier frase.
5. **Escribir mal la palabra.** Recuerda cambios como *easy → easily* y *happy → happiness*.
6. **No leer el texto entero.** Algunas respuestas dependen del sentido general, no solo de las dos palabras cercanas al hueco.

## 8. Practica: mini ejercicio de Word Formation

Completa cada frase con una palabra formada a partir de la palabra en mayúsculas. Escribe tus respuestas antes de mirar las soluciones.

1. The instructions were very ______, so nobody had any questions. (HELP)
2. She completed the task ______ and without making mistakes. (CARE)
3. Regular practice is the key to ______ in language learning. (SUCCEED)
4. The weather was so ______ that we decided to stay indoors. (STORM)
5. There are several interesting tourist ______ near the city. (ATTRACT)
6. It is ______ to learn a language without practising it. (POSSIBLE)
7. The hotel staff were very ______ to all the guests. (FRIEND)
8. We were surprised by the ______ of the final result. (ACCURATE)

<summary><strong>Ver soluciones y explicación</strong></summary>

1. **HELPFUL** — adjetivo que describe *instructions*.
2. **CAREFULLY** — adverbio que describe cómo completó la tarea.
3. **SUCCESS** — sustantivo después de *the key to*.
4. **STORMY** — adjetivo que describe *weather*.
5. **ATTRACTIONS** — sustantivo plural después de *several*.
6. **IMPOSSIBLE** — adjetivo negativo: aprender sin practicar no es posible.
7. **FRIENDLY** — adjetivo que describe al personal (*staff*).
8. **ACCURACY** — sustantivo después de *the*.

## 9. Cómo preparar esta parte antes del examen

- Dedica unos minutos al día a crear familias de palabras.
- Haz una lista personal con la palabra base, el sustantivo, el adjetivo, el adverbio y las formas negativas.
- Practica con textos completos, no solo con frases sueltas.
- Corrige tus errores y apunta por qué fallaste: categoría, prefijo, sufijo, plural, significado u ortografía.
- Cuando hagas un simulacro, reserva unos ocho minutos para esta parte y revisa el texto al terminar.

**La clave es pensar primero en la función gramatical y después en la transformación.** Si identificas qué tipo de palabra necesita cada hueco, reducirás mucho las opciones y trabajarás con más seguridad.
